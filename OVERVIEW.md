# Clibrary Overview

## What is Clibrary?

**Clibrary is your personal design learning system** - a tool that helps you collect, study, and recreate the best web designs you find online, then automatically turns them into reusable components for your own projects.

Think of it as Spotify for web design - but instead of playlists of songs, you're building a library of design patterns and components you can actually use.

## The Problem It Solves

We've all been there:
- You see an amazing website with a perfect hero section
- You take a screenshot... that gets lost in your downloads folder
- You bookmark it... but never look at it again
- You try to recreate it from memory... but can't quite get it right
- You want to learn from it... but don't know where to start

**Clibrary changes this workflow completely.**

## How It Works

### 1. 📌 **Collect** - Save Any Website That Inspires You
- See a cool site? Add it to your queue with one click
- It stays in your visual library with live preview
- Add notes about what you loved ("amazing card hover effect!")
- Tag it for later ("minimal", "good-typography", "saas-landing")

### 2. 🔍 **Study** - Learn By Recreating
- When you're ready, clone the design as a learning exercise
- Break it down into components
- Understand the patterns and techniques
- Extract the color palettes, fonts, spacing systems

### 3. 🧩 **Componentize** - Turn Designs Into Reusable Pieces
- Automatically extract common patterns across all your clones
- Generate React/Vue/HTML components
- Convert to shadcn/ui format for easy use
- Build your personal component library

### 4. 🚀 **Reuse** - Ship Faster With Your Library
- Need a hero section? You have 20 variations ready
- Want that button style? It's already componentized
- Building a new project? Mix and match from your library

## Key Features

### 🎯 Inspiration Queue
- Save sites instantly while browsing
- They show up in your library with live preview
- Even if you never clone them, you have a visual reference
- Add priority levels (high/medium/low) to organize your learning

### 🖼️ Visual Gallery
- See all your inspirations and clones in one place
- Live previews of original sites
- Side-by-side comparison of original vs. your clone
- Filter by style, industry, components used

### 🔧 Smart Extraction
- Automatically identifies reusable components
- Extracts design tokens (colors, fonts, spacing)
- Recognizes common patterns across projects
- Generates clean, usable code

### 📦 Component Library
- Shadcn/ui compatible components
- Full TypeScript support
- Tailwind CSS styling
- Copy-paste ready

### 🔄 Multiple Sources
- Clone from live websites
- Import from your GitHub repos
- Pull from local projects
- Connect to Vercel/Netlify deployments

## The Philosophy

**Learn by doing, not copying.**

Clibrary is built on the belief that the best way to improve your web design skills is to:
1. Study what works in the wild
2. Understand why it works by recreating it
3. Build your own version that you actually understand
4. Create a personal library of patterns you can use and modify

It's like learning to cook by recreating restaurant dishes - you're not stealing recipes, you're learning techniques that become part of your own style.

## Getting Started Is Simple

### Step 1: Install Clibrary
```bash
git clone https://github.com/yourusername/clibrary
npm install
npm run dev
```

### Step 2: Add Your First Inspiration
```bash
npm run queue:add --url=https://linear.app --notes="Amazing command palette"
```

### Step 3: View Your Library
Open http://localhost:3000 and see your inspiration library

### Step 4: Start Learning
Pick a site from your queue and start recreating it. Clibrary guides you through the process.
